# VidFlow — fundamentos com Node.js

Projeto de estudos que apresenta o VidFlow, uma interface de navegação por vídeos que consulta uma API local. Esta etapa explora ferramentas do ecossistema Node.js para organizar e padronizar o desenvolvimento front-end.

## O que o projeto demonstra

- Listagem de vídeos carregados de uma API local com JSON Server
- Organização de código com ESLint e Prettier
- Uso de Node.js e npm no fluxo de desenvolvimento

## Tecnologias

JavaScript, Node.js, npm, Axios, JSON Server, ESLint e Prettier.

## Como executar

Requer Node.js instalado.

```bash
npm install
npm run api-local
```

Com a API rodando, abra `index.html` no navegador. O script `api-local` inicia o JSON Server com `backend/videos.json`.

## Contexto

Projeto educacional da trilha de desenvolvimento front-end. Esta versão registra a etapa anterior à migração para Vite.
